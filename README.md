# nmt-prep-bot

Telegram-бот для підготовки до НМТ (Історія України, Українська мова + довільні «інші предмети»).
Python 3.11 · aiogram 3 · aiosqlite · APScheduler.

## Запуск

```bash
cp .env.example .env        # заповніть BOT_TOKEN та ADMIN_ID
docker compose up -d --build
docker compose logs -f
```

Без Docker: `pip install -r requirements.txt && python main.py`.
База й логи — у `storage/` (volume), стартові дані — у `data/*.json`
(`dates`, `accents`, `mnemonics`, `foreign_words`, `phrases`). Seed виконується лише для порожніх таблиць;
нові пакети матеріалів до вже заселених таблиць додаються один раз (див. `IMPORT_PACKS` у `database/db.py`).

## Для користувача

| Команда | Що робить |
|---|---|
| `/now` | картка зараз: обери тему (історія, мова, наголоси, іншомовні слова, фразеологізми, інші предмети, помилки) |
| `/quiz` | раунд із 10 питань у вигляді опитувань Telegram (хибні варіанти підбираються автоматично) |
| `/mistakes` | лише картки, на які остання відповідь була «Не знав» |
| `/stats` | відповіді, % правильних, серія днів, слабкі теми, скільки пора повторити |
| `/find слово` | пошук по всій базі (без урахування регістру й наголосів) |
| `/settings` | теми, інтервал (1/2/3/4/6/12/24 год), ліміт карток на добу, «слово дня» |
| `/quiet 22 8` | тихий режим (за київським часом) |
| `/stop` | призупинити розсилку (поновити — `/start`) |

Під карткою: «Показати відповідь» → «✅ Знав» / «❌ Не знав». Відповіді керують **інтервальним повторенням**
(система «коробок»: помилка → повтор за ~2 год; далі 1 → 3 → 7 → 21 день). Половина карток — це повторення того,
що пора повторити; засвоєні показуються рідше.

**Розклад.** Щогодини о :00 бот перевіряє кожного користувача: тихий режим, власний інтервал (відлік від кінця
тихого режиму), добовий ліміт, чергування предметів (індивідуальне, серед увімкнених тем). Раз на добу —
«слово дня». Після простою (відключення світла) бот через ~45 с надсилає по одній пропущеній картці.

## Адмін-панель (`/admin`, лише ADMIN_ID)

- **Додавання, перегляд, редагування будь-якого поля, видалення** — для дат, наголосів, фраз для наголосів,
  відповідників іншомовних слів, фразеологізмів, пам'яток із фото та завдань «інших предметів».
- **Оголошення всім** — свій текст (з форматуванням Telegram) або фото з підписом; попередній перегляд і
  підтвердження; йде негайно, незалежно від часу й тихого режиму.
- **Розсилка завдань зараз** — одна картка або квіз-опитування з обраної теми всім активним користувачам,
  незалежно від розкладу, ліміту й тихого режиму.
- **Імпорт із файлу** — CSV (UTF-8, `;` або `,`) чи JSON; дублікати пропускаються, помилкові рядки перелічуються.
  Колонки: дати `дата;подія` · наголоси `слово;підказка` · іншомовні `слово;відповідник` ·
  фразеологізми `фразеологізм;значення` · фрази `категорія;фраза` · завдання `предмет;питання;відповідь`.
- **Інші предмети** — довільні завдання «питання → відповідь» за темами (математика, англійська…): через діалог
  або імпорт. Теми з'являються в `/now`, `/quiz` і чергуванні, щойно в них є завдання.
- **Бекап бази** — кнопка в панелі; крім того, щодоби о 04:05 копія автоматично надходить вам у Telegram
  (вимкнути: `AUTO_BACKUP=0` у `.env`).
- **Сповіщення** — «Бот запущено» (із тривалістю перерви після відключення світла) та серйозні помилки
  (однакову — не частіше ніж раз на 10 хвилин).

## Формат наголосів

- Слово в розділі «Наголоси»: наголошена голосна — велика літера (`каталОг`).
  Два допустимі варіанти — дві великі голосні (`мАбУть` = «ма́буть» і «мабу́ть»).
  Для омографів підказка може починатися з уточнення в дужках: `(користь) Наголос на 1-му складі.`
- Фраза: велика голосна всередині слова (`піцЕрія`) або знак наголосу (піце́рія).

## Відключення світла

`restart: unless-stopped` + `sudo systemctl enable docker` піднімають бота після перезавантаження сервера;
без інтернету він чекає й повторює спроби; команди, надіслані під час простою, Telegram зберігає до 24 годин.
Основний джерело наголосів: перелік НМТ-2025; для звірки: https://osvita.ua/test/training/materialy-instrumenty/65116/
