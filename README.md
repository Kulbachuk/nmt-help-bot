# nmt-prep-bot

Telegram-бот для підготовки до НМТ (Історія України + Українська мова).
Python 3.11 · aiogram 3 · aiosqlite · APScheduler.

## Запуск

```bash
cp .env.example .env        # заповніть BOT_TOKEN та ADMIN_ID
docker compose up -d --build
docker compose logs -f
```

Без Docker: `pip install -r requirements.txt && python main.py`.

SQLite-база та логи зберігаються в `storage/` (volume), стартові дані — у `data/*.json`
(`dates.json`, `accents.json`, `mnemonics.json`, `foreign_words.json`). Seed виконується лише для порожніх таблиць.

## Картки

- **Історія:** дати та пам'ятки з фото (кнопка «Показати відповідь» відкриває рік / назву).
- **Українська мова:** наголоси, римовані фрази для запам'ятовування наголосів та
  відповідники іншомовних слів («абзац» → «відступ»). У `/now` кожну тему можна обрати окремо.

Розсилка за годинником Києва о 00:00, 02:00, … 22:00; тихий режим за замовчуванням 22:00–08:00
(змінюється командою `/quiet 23 7`). Предмети чергуються строго: Історія → Мова → Історія → …

## Адмін-панель (`/admin`, лише ADMIN_ID)

- додавання: дат, наголосів, фраз для наголосів, відповідників іншомовних слів, пам'яток з фото;
- перегляд усіх записів по розділах зі сторінками;
- редагування будь-якого поля запису (включно з фото пам'ятки);
- видалення з підтвердженням;
- статистика.

## Формат наголосів

- Слово в розділі «Наголоси»: наголошена голосна — велика літера (`алфавІт`).
- Фраза: велика голосна всередині слова (`піцЕрія`) або знак наголосу (піце́рія).
  Якщо наголос на першій літері слова — лише знак наголосу.
